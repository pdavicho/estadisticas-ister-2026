Instalación y Primeros Pasos en RStudio

Autor/a

Ing. David Minango PhD

Duración estimada: 90 minutos | Dificultad: Básica-Media Herramienta principal: R / RStudio

Este taller verifica que su entorno está correctamente configurado y le da práctica con los conceptos básicos de R.

Parte 1 — Configuración del Entorno

1.1 Verifique que R y RStudio están instalados ejecutando en la consola de RStudio:

R.version.string   # Debe mostrar la versión de R
rstudioapi::versionInfo()$version  # Versión de RStudio

1.2 Instale los paquetes esenciales del curso:

# Ejecute este bloque completo (puede tardar varios minutos)
paquetes_necesarios <- c(
  "dplyr",      # manipulación de datos
  "ggplot2",    # visualizaciones
  "readxl",     # importar Excel
  "tidyr",      # limpieza de datos
  "lubridate",  # fechas
  "psych",      # estadística descriptiva avanzada
  "moments"     # asimetría y curtosis
)

for (pkg in paquetes_necesarios) {
  if (!requireNamespace(pkg, quietly = TRUE)) {
    install.packages(pkg)
    cat("✅ Instalado:", pkg, "\n")
  } else {
    cat("✔ Ya existe:", pkg, "\n")
  }
}
cat("\n🎉 Todos los paquetes están listos!\n")

1.3 Tome una captura de pantalla de su consola mostrando los paquetes instalados.

Parte 3 — Vectores Básicos

# ─── Crear vectores ───────────────────────────────
notas_python <- c(88, 75, 92, 68, 85, 79, 91, 83, 70, 87)
notas_R      <- c(90, 82, 88, 75, 93, 78, 86, 84, 72, 89)

# ─── Operaciones con vectores ──────────────────────
# R opera elemento por elemento automáticamente
diferencia <- notas_R - notas_python  # Imprima esto

# Estadísticas de cada materia
cat("=== PYTHON ===\n")
cat("Media:", mean(notas_python), "\n")
cat("Mediana:", median(notas_python), "\n")
cat("Desv. Estándar (muestral):", sd(notas_python), "\n")
cat("Rango:", diff(range(notas_python)), "\n")

cat("\n=== R ===\n")
cat("Media:", mean(notas_R), "\n")
cat("Mediana:", median(notas_R), "\n")
cat("Desv. Estándar (muestral):", sd(notas_R), "\n")

# ─── Subsetting (acceder a elementos) ─────────────
cat("\nPrimera nota de Python:", notas_python[1])   # R empieza en 1, no en 0!
cat("\nÚltima nota de Python:", notas_python[length(notas_python)])
cat("\nNotas 3 a 6:", notas_python[3:6])

# ─── Filtros lógicos ──────────────────────────────
aprobados_python <- notas_python[notas_python >= 70]
cat("\nAprobados en Python:", aprobados_python)
cat("\nCuántos aprobaron:", length(aprobados_python), "/", length(notas_python))

Preguntas:

3.1 ¿Cuál tiene mejor promedio, Python o R? ¿Por cuánto?

3.2 En R, los vectores empiezan en el índice 1 (no en 0 como Python). ¿Qué pasa si intenta notas_python[0]?

3.3 ¿Cuántos estudiantes reprobaron (nota < 70) en Python? Use un filtro lógico.

Parte 4 — Estadística Descriptiva con R

# ─── summary() da un resumen completo ─────────────
notas_python <- c(88, 75, 92, 68, 85, 79, 91, 83, 70, 87)

cat("=== RESUMEN COMPLETO ===\n")
print(summary(notas_python))

# ─── Quantiles ────────────────────────────────────
cat("\nPercentiles:\n")
cat("Q1 (25%):", quantile(notas_python, 0.25), "\n")
cat("Q2 (50%):", quantile(notas_python, 0.50), "\n")
cat("Q3 (75%):", quantile(notas_python, 0.75), "\n")
cat("P90 (90%):", quantile(notas_python, 0.90), "\n")

# ─── Gráficos básicos ─────────────────────────────
par(mfrow=c(2, 2))

# Histograma
hist(notas_python, col="#0055a5", border="white",
     main="Histograma de Notas", xlab="Nota")
abline(v=mean(notas_python), col="red", lwd=2, lty=2)

# Boxplot
boxplot(notas_python, col="#e8f4fd", border="#003366",
        main="Boxplot de Notas", ylab="Nota")

# Diagrama de puntos
stripchart(notas_python, method="jitter",
           pch=19, col="#0055a5",
           main="Diagrama de Puntos", xlab="Nota")
abline(v=mean(notas_python), col="red", lwd=2)

# Gráfico de línea (evolución)
plot(1:length(notas_python), notas_python,
     type="o", col="#003366", pch=16,
     main="Notas por Estudiante", xlab="Estudiante", ylab="Nota")
abline(h=mean(notas_python), col="red", lty=2)
abline(h=70, col="green", lty=3)

par(mfrow=c(1,1))
