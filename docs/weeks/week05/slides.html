Instalación

Paso 1: Instalar R base - Descargar de: cran.r-project.org - Seleccionar: Windows / macOS / Linux - Instalar con opciones por defecto

Paso 2: Instalar RStudio - Descargar de: posit.co/download/rstudio-desktop/ - Instalar la versión Desktop gratuita

Note

RStudio es un IDE (entorno de desarrollo integrado) que hace que trabajar con R sea mucho más cómodo. No es R en sí, sino la interfaz para usarlo.

Los 4 Paneles de RStudio

Panel 1: Editor (Scripts)

  • Aquí escribe su código
  • Se guarda como archivo .R
  • Ctrl+Enter para ejecutar línea
  • Ctrl+Shift+Enter para ejecutar todo

Panel 2: Environment

  • Muestra todas las variables creadas
  • Listas, vectores, data frames visibles
  • History: historial de comandos

Panel 3: Consola

  • Ejecuta R en tiempo real
  • Resultados aparecen aquí
  • También puede escribir directamente

Panel 4: Files/Plots/Help

  • Files: navegador de archivos
  • Plots: gráficos generados
  • Packages: paquetes instalados
  • Help: documentación

Primeros Comandos en R

# Esto es un comentario (R ignora las líneas que empiezan con #)

# Operaciones básicas
2 + 3        # 5
10 - 4       # 6
3 * 7        # 21
15 / 4       # 3.75
2^8          # 256
sqrt(16)     # 4
abs(-7)      # 7
log(100)     # 4.60517 (logaritmo natural)
log10(100)   # 2 (logaritmo base 10)

En R, el operador de asignación es <- (aunque = también funciona):

x <- 10
y <- 5
x + y  # 15

Tipos de Datos en R

# Numeric (numérico)
edad    <- 25L         # entero (integer)
salario <- 1500.50     # decimal (double)

# Character (texto)
nombre  <- "David"
ciudad  <- 'Quito'

# Logical (lógico)
activo  <- TRUE
inactivo <- FALSE

# Verificar tipos
class(edad)     # "integer"
class(salario)  # "numeric"
class(nombre)   # "character"
class(activo)   # "logical"

# Convertir tipos
as.numeric("3.14")   # 3.14
as.character(42)     # "42"
as.logical(1)        # TRUE

Paquetes en R

Los paquetes extienden las capacidades de R base:

# Instalar un paquete (solo una vez)
install.packages("dplyr")
install.packages("ggplot2")
install.packages("readxl")

# Cargar el paquete para usarlo
library(dplyr)
library(ggplot2)

# Ver todos los paquetes instalados
installed.packages()[, "Package"]

# Obtener ayuda sobre un paquete o función
?dplyr
help("mean")
?ggplot2

Tip

Los paquetes más importantes para este curso: - dplyr — manipulación de datos - ggplot2 — visualización - readxl — importar Excel - tidyr — limpieza de datos
