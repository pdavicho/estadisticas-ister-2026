📊 group_by con Múltiples Variables

Hasta ahora agrupamos por una sola variable. En la práctica casi siempre necesitamos cruzar dos o más dimensiones a la vez (por ejemplo: región y género).

# Agrupar por MÚLTIPLES variables a la vez
datos %>%
  group_by(region, genero) %>%
  summarise(
    n     = n(),
    media = round(mean(salario), 2),
    .groups = "drop"   # evita el mensaje de "regroupment" de dplyr
  )

.groups = "drop" le dice a dplyr que, después de resumir, no deje el resultado agrupado. Si no lo especifica, R muestra un mensaje informativo (no es un error) recordándole que el resultado sigue agrupado.

# n_distinct(): cuántos valores ÚNICOS hay por grupo
datos %>%
  group_by(region) %>%
  summarise(provincias_distintas = n_distinct(provincia))

# across(): aplicar la MISMA función a varias columnas
datos %>%
  group_by(sector) %>%
  summarise(across(c(salario, edad, anios_exp),
                    ~ round(mean(.x, na.rm = TRUE), 1)))

across() evita repetir mean(salario), mean(edad), mean(anios_exp) tres veces. La sintaxis ~ round(mean(.x, na.rm=TRUE), 1) significa “aplica esta función a cada columna, donde .x representa la columna actual”.

🔗 Combinar Tablas con Joins

En la vida real, los datos casi nunca vienen en una sola tabla. Vamos a crear una segunda tabla pequeña con información a nivel de región y unirla a nuestro dataset de personas.

# Tabla secundaria: información socioeconómica por región
info_regional <- data.frame(
  region             = c("Costa", "Sierra", "Oriente", "Insular"),
  capital_region     = c("Guayaquil", "Quito", "Puyo", "Pto. Baquerizo Moreno"),
  poblacion_millones = c(7.5, 8.2, 0.85, 0.03),
  pib_per_capita     = c(6100, 6800, 5200, 9400)
)
info_regional
# ── left_join(): conserva TODAS las filas de "datos" ──
# y agrega columnas de info_regional donde haya coincidencia
datos_completo <- datos %>%
  left_join(info_regional, by = "region")

head(datos_completo[, c("id","region","salario","pib_per_capita")])

# ── inner_join(): solo filas que coinciden en AMBAS tablas ─
datos %>% inner_join(info_regional, by = "region") %>% nrow()

# ── anti_join(): filas de "datos" que NO tienen coincidencia ─
# (útil para control de calidad: encontrar valores mal escritos)
datos %>% anti_join(info_regional, by = "region") %>% nrow()

Piense en dos hojas de Excel — una con datos de personas, otra con datos de regiones — y la columna region como la “llave” que las conecta. left_join es como un VLOOKUP que nunca pierde filas de la tabla izquierda, aunque no encuentre coincidencia (deja NA).

# ¿El salario se relaciona con el PIB per cápita de la región?
datos_completo %>%
  group_by(region, pib_per_capita) %>%
  summarise(salario_medio = round(mean(salario), 2), .groups = "drop") %>%
  arrange(desc(pib_per_capita))

🔄 tidyr: Cambiar la Forma de los Datos

tidyr resuelve un problema distinto al de dplyr: no cambia qué datos tenemos, sino la forma en la que están organizados (ancho ↔︎ largo).

library(tidyr)

# Datos en formato ANCHO: una columna por parcial
notas_wide <- data.frame(
  estudiante = c("Ana", "Luis", "Marco"),
  parcial1   = c(8.5, 7.0, 9.2),
  parcial2   = c(9.0, 6.5, 8.8),
  parcial3   = c(7.8, 8.0, 9.5)
)
notas_wide
# ── pivot_longer(): de ANCHO a LARGO ──────────────────
notas_long <- notas_wide %>%
  pivot_longer(cols = starts_with("parcial"),
               names_to = "parcial", values_to = "nota")
notas_long

# Con formato largo, ahora SÍ se puede usar group_by/summarise
notas_long %>%
  group_by(estudiante) %>%
  summarise(promedio = round(mean(nota), 2))

# ── pivot_wider(): el camino inverso ──────────────────
notas_long %>%
  pivot_wider(names_from = parcial, values_from = nota)

Regla mnemotécnica: “longer = más filas, menos columnas”; “wider = más columnas, menos filas”. group_by/summarise de dplyr funcionan mejor en formato largo — por eso casi siempre se usa pivot_longer antes de resumir.

📈 Análisis Descriptivo Completo (Pipeline Integrador)

Cerramos uniendo todo lo visto en las Semanas 7 y 8 en un solo flujo de trabajo: importar, limpiar, unir tablas, agrupar por varias variables y presentar un resumen final.

library(dplyr)
library(tidyr)

# PASO 1 — Importar
datos <- read.csv("datos_salarios_ecuador_app2.csv", stringsAsFactors = FALSE)

# PASO 2 — Limpiar
datos$salario[is.na(datos$salario)] <- median(datos$salario, na.rm = TRUE)
datos <- na.omit(datos)

# PASO 3 — Unir con información regional
datos <- datos %>% left_join(info_regional, by = "region")

# PASO 4 — Agrupar por múltiples variables y resumir
resumen_final <- datos %>%
  group_by(region, genero) %>%
  summarise(
    n       = n(),
    media   = round(mean(salario), 2),
    mediana = median(salario),
    cv      = round(sd(salario) / mean(salario) * 100, 1),
    .groups = "drop"
  ) %>%
  arrange(region, genero)

print(as.data.frame(resumen_final))

# PASO 5 — Presentar en formato ancho (una columna por género)
resumen_final %>%
  select(region, genero, media) %>%
  pivot_wider(names_from = genero, values_from = media) %>%
  mutate(brecha_pct = round((Hombre - Mujer) / Hombre * 100, 1))

🐍 Equivalentes en Python

import pandas as pd

df = pd.read_csv("datos_salarios_ecuador_app2.csv")
df['salario'] = df['salario'].fillna(df['salario'].median())
df = df.dropna()

info_regional = pd.DataFrame({
    'region': ['Costa','Sierra','Oriente','Insular'],
    'pib_per_capita': [6100, 6800, 5200, 9400]
})

# join (merge) — equivalente a left_join
df = df.merge(info_regional, on='region', how='left')

# group_by múltiple + summarise (agg)
resumen = df.groupby(['region','genero'])['salario'].agg(
    n='count', media='mean', mediana='median'
).round(2).reset_index()
print(resumen)

# pivot_wider (equivalente: pivot_table / pivot)
tabla_ancha = resumen.pivot(index='region', columns='genero', values='media')
print(tabla_ancha)

# pivot_longer (equivalente: melt)
tabla_larga = tabla_ancha.reset_index().melt(
    id_vars='region', var_name='genero', value_name='media')
print(tabla_larga)

group_by() dplyr Agrupa filas por una o varias variables
summarise() dplyr Resume cada grupo (media, n, etc.)
across() dplyr Aplica una función a varias columnas a la vez
n_distinct() dplyr Cuenta valores únicos dentro de un grupo
left_join() dplyr Une tablas conservando todas las filas de la izquierda
inner_join() dplyr Une tablas conservando solo coincidencias

    id_vars='region', var_name='genero', value_name='media')
print(tabla_larga)
