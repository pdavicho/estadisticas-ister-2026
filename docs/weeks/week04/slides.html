De la Estadística Descriptiva a la Probabilidad

Hasta ahora: Describimos datos que ya tenemos (pasado) - Media, mediana, moda, varianza, desviación estándar

Ahora: Modelamos lo que puede ocurrir (futuro) - ¿Cuál es la probabilidad de que un servidor falle mañana? - ¿Qué tan probable es que un estudiante apruebe?

La probabilidad es el lenguaje matemático de la incertidumbre.

Variable Aleatoria

Una variable aleatoria (V.A.) es una función que asigna un valor numérico a cada resultado posible de un experimento aleatorio.

Discreta

Toma valores contables (enteros)

Ejemplos: - X = número de bugs en un código - X = número de llamadas por hora - X = resultado al lanzar un dado

Valores posibles: {0, 1, 2, 3, …}

Continua

Toma cualquier valor en un intervalo

Ejemplos: - X = tiempo de respuesta de un servidor - X = temperatura del CPU - X = peso de un archivo (MB)

Valores posibles: [0, ∞)

Función de Probabilidad (Variable Discreta)

Para una variable discreta X, la función \(P(X = x)\) debe cumplir:

\[\sum_{x} P(X = x) = 1 \quad \text{y} \quad P(X = x) \geq 0 \text{ para todo } x\]

Ejemplo: X = número de errores en una línea de código

X 0 1 2 3 4
P(X=x) 0.40 0.30 0.20 0.07 0.03

Verificación: \(0.40 + 0.30 + 0.20 + 0.07 + 0.03 = 1.00\) ✅

Valor Esperado y Varianza (Discreta)

\[E(X) = \mu = \sum_{x} x \cdot P(X = x)\]

\[Var(X) = \sigma^2 = \sum_{x} (x - \mu)^2 \cdot P(X = x)\]

Ejemplo: Con la tabla anterior (errores por línea)

\[E(X) = 0(0.40) + 1(0.30) + 2(0.20) + 3(0.07) + 4(0.03) = 1.03 \text{ errores}\]

El valor esperado es el promedio a largo plazo si repitiéramos el experimento muchas veces. En este caso, esperamos ~1 error por línea de código.

Función de Densidad (Variable Continua)

Para una variable continua, \(P(X = x) = 0\) para cualquier valor exacto. En cambio usamos la función de densidad \(f(x)\):

\[P(a \leq X \leq b) = \int_a^b f(x) dx \quad \text{y} \quad \int_{-\infty}^{\infty} f(x) dx = 1\]

La probabilidad es el área bajo la curva en un intervalo.

La Distribución Normal

La distribución más importante en estadística:

\[f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}\]

Propiedades: - Simétrica alrededor de \(\mu\) (media = mediana = moda) - Forma de campana - Completamente definida por \(\mu\) y \(\sigma\)

Regla empírica: - \(P(\mu - \sigma \leq X \leq \mu + \sigma) \approx 68\%\) - \(P(\mu - 2\sigma \leq X \leq \mu + 2\sigma) \approx 95\%\) - \(P(\mu - 3\sigma \leq X \leq \mu + 3\sigma) \approx 99.7\%\)

Distribución Normal Estándar (Z)

Estandarización: convierte cualquier normal en la normal estándar \(N(0,1)\):

\[Z = \frac{X - \mu}{\sigma}\]

Ejemplo: Los tiempos de carga de un servidor siguen \(N(\mu=3, \sigma=0.5)\) seg

¿Cuál es la probabilidad de que el tiempo sea menor a 3.5 segundos?

\[Z = \frac{3.5 - 3}{0.5} = 1.0 \quad \Rightarrow \quad P(X < 3.5) = P(Z < 1) \approx 84.13\%\]

Distribuciones Discretas Importantes

Bernoulli

Un experimento con dos resultados (éxito/fracaso): \[P(X=1) = p \quad P(X=0) = 1-p\] \(E(X) = p \quad Var(X) = p(1-p)\)

Binomial

n repeticiones Bernoulli independientes: \[P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}\] \(E(X) = np \quad Var(X) = np(1-p)\)

Ejemplo Binomial: Si el 30% de los sistemas tienen un bug, en una muestra de 10 sistemas, ¿cuántos esperamos con bugs? \[E(X) = 10 \times 0.30 = 3 \text{ sistemas}\]

Resumen
