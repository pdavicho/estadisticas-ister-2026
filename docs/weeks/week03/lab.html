Medidas de Dispersión para Datos Agrupados

Autor/a

Ing. David Minango PhD

Duración estimada: 90 minutos | Dificultad: Media Herramientas: Python y R | Dataset: Notas de estudiantes (datos reales simulados)

Contexto

El departamento académico del ISTER registró las calificaciones finales de 42 estudiantes de la carrera de Sistemas en el período anterior. Como analista, debe calcular las medidas de dispersión para determinar si el rendimiento fue homogéneo o heterogéneo.

Dataset — Calificaciones finales (sobre 100):

72, 85, 63, 91, 78, 55, 88, 74, 67, 93,
80, 58, 76, 84, 69, 96, 71, 62, 87, 75,
60, 82, 70, 88, 65, 79, 92, 68, 77, 83,
57, 86, 73, 61, 90, 76, 64, 85, 70, 94,
59, 81

Ejercicio 1 — Tabla de Frecuencias con Dispersión (Python)

import pandas as pd

    72, 85, 63, 91, 78, 55, 88, 74, 67, 93,

plt.bar(marcas, frecuencias, width=ancho, color='#0055a5',
        edgecolor='white', alpha=0.8)
plt.axvline(media, color='red', lw=2, ls='--', label=f'Media={media:.1f}')
plt.axvspan(media-desv_std, media+desv_std, alpha=0.15, color='red', label=f'x̄±s')

plt.ylabel('Número de Estudiantes')

plt.legend()

Ejercicio 2 — Análisis en R

notas <- c(
  72, 85, 63, 91, 78, 55, 88, 74, 67, 93,
  80, 58, 76, 84, 69, 96, 71, 62, 87, 75,
  60, 82, 70, 88, 65, 79, 92, 68, 77, 83,
  57, 86, 73, 61, 90, 76, 64, 85, 70, 94,
  59, 81
)

n   <- length(notas)
k   <- ceiling(1 + 3.322 * log10(n))
c   <- # TU CÓDIGO
ini <- 55
lim <- seq(ini, ini + k*c, by = c)

h     <- hist(notas, breaks = lim, plot = FALSE)
mi    <- (h$breaks[-length(h$breaks)] + h$breaks[-1]) / 2
fi    <- h$counts
media <- sum(fi * mi) / n

# Varianza agrupada
varianza <- sum(fi * (mi - media)^2) / n
desv_std <- sqrt(varianza)
cv       <- (desv_std / media) * 100

cat(sprintf("Media:           %.2f pts\n", media))
cat(sprintf("Varianza:        %.4f\n", varianza))
cat(sprintf("Desv. Estándar:  %.4f pts\n", desv_std))
cat(sprintf("Coef. Variación: %.2f%%\n", cv))

# ¿Cuántos estudiantes están dentro de x̄ ± s?
dentro_1s <- sum(notas >= media - desv_std & notas <= media + desv_std)
dentro_2s <- sum(notas >= media - 2*desv_std & notas <= media + 2*desv_std)
cat(sprintf("\nDentro de x̄±s:  %d/%d (%.1f%%)\n", dentro_1s, n, 100*dentro_1s/n))
cat(sprintf("Dentro de x̄±2s: %d/%d (%.1f%%)\n", dentro_2s, n, 100*dentro_2s/n))

# Visualización
hist(notas, breaks = lim, col = "#0055a5", border = "white",
     main = "Calificaciones ISTER con Dispersión", xlab = "Nota")
abline(v = media, col = "red", lwd = 2, lty = 2)
abline(v = c(media-desv_std, media+desv_std), col = "orange", lwd = 2, lty = 3)
abline(v = 70, col = "black", lwd = 1.5, lty = 4)
legend("topright", cex = 0.8,
       legend = c(paste("Media=",round(media,1)),
                  paste("±s=",round(desv_std,1)),
                  "Aprobación (70)"),
       col = c("red","orange","black"), lty = c(2,3,4), lwd = 2)
